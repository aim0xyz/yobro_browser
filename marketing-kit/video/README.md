# YOBRO promo video

`yobro-promo-mockdata-1080p.mp4` is a 1920×1080 launch teaser assembled only from the privacy-safe marketing assets in this repository.

The visible Northstar Studio workspace, project names, tasks, percentages and local `127.0.0.1` address are fictional demo data. No browser profile, inbox, history, account, API key or production URL is read during rendering. Generated scene images have their source metadata removed.

Rebuild on macOS with ImageMagick and FFmpeg:

```sh
./marketing-kit/video/build-promo.sh
```
